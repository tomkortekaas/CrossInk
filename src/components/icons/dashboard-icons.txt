# Dashboard widget-grid icon set.
#
# ONE MANIFEST, TWO CONSUMERS. This file is the single source of truth for the
# dashboard icon set: it generates both the firmware header
# (src/components/icons/dashboardIcons.h, via
# freeink-sdk/libs/assets/Icons/tools/gen_icons.py) and the iPhone composer's
# picker. Keeping one list is what stops the two sides from drifting apart —
# see docs/superpowers/specs/2026-08-15-widget-grid-editor-design.md.
#
# LINE ORDER IS THE WIRE FORMAT. Line N (counting non-comment lines from 1) is
# iconId N in the per-widget style word; iconId 0 means "no icon". APPEND ONLY.
# Reordering or removing a line silently repoints every dashboard already stored
# on a device, because the X3 renders from its last-known-good package.
#
# Cap is 65: the style word gives the icon id 7 bits, and 65 entries at 32 and
# 48 px cost roughly 13 KB of flash.
#
# Format: alias = lucide-name. The alias is the C identifier; the lucide name
# picks the SVG from freeink-sdk/libs/assets/Icons/lucide/icons.
